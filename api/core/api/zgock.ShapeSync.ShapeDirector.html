TryAddTemplate(ShapeSyncShapeTemplate, out StackMachineDiagnostic)

Adds a validated Template-derived Shape to the authoritative runtime list.

public bool TryAddTemplate(ShapeSyncShapeTemplate template, out StackMachineDiagnostic diagnostic)

Parameters

template ShapeSyncShapeTemplate

The authoring Template to convert into a runtime Shape.

diagnostic StackMachineDiagnostic

A structured rejection or auto-compile diagnostic.

Returns

bool

true when the runtime list accepted the Shape and any requested auto-compile succeeded.

Remarks

A concrete Shape type and Priority form a logical wearing slot: existing Runtime Shapes of the added Shape's concrete type at the same priority are removed before it is added. Shapes of other concrete types, including Morph Shapes, remain in the logical state. The supplied Template is then appended to TemplateList as an inspector input convenience; replacement never mutates the existing TemplateList entries.

TransactionStarting

Raised immediately before a Mesh or Material transaction may mutate the live Figure.

public event Action TransactionStarting

Event Type

Action

Remarks

This event is raised only before a Mesh or Material execution can mutate live Figure topology. A successful empty-recipe commit has no such execution and raises only TransactionCommitted. Listeners that retain derived Figure hierarchies must release them here, rather than after topology callbacks observe a partially changed hierarchy.
