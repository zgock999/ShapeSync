Remarks

This component owns only cross-material ordering and escrow. It does not mutate a Material Proxy or add transaction state to lower layers. A request containing a TEXTURE block resolves the active scene Host through TextureStaticMachineFactory; color-only and UV-only requests do not create or resolve a Texture Host.

Remarks
