Remarks

The recorded Schema provenance must have passed TryValidate(AtlasSchemaDocument, out StackMachineDiagnostic). Identity tokens are caller-authored canonical values: they are never normalized, and equality is Ordinal. MaterialIds absent from the current build are intentionally ignored here; the Baker owns their Info-level Schema reconciliation. A malformed or duplicate current source token is rejected only when its MaterialId is shared with the Schema. The Editor supplies tokens from its authoritative source; the Baker supplies tokens from its actual build input.
