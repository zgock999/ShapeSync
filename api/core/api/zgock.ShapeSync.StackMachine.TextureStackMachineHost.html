Remarks

TextureStaticMachineFactory resolves this component for Texture callers but never owns its Grid, hall allocation, request queue, delivery, or disposal lifecycle. A Host is scoped to its Unity scene and is neither persistent nor a global service.

Methods

CreateOrigin()

Issues one opaque origin token owned by this scene-local host.

public TextureExecutionOriginKey CreateOrigin()

Returns

TextureExecutionOriginKey

A new host-issued origin token.

Remarks

Callers retain the returned token for one logical request series and pass it again when a newer unsubmitted request is intended to replace the previous request. Tokens do not require explicit release; host teardown invalidates their owner identity. The sequence is deliberately host-local and is never exposed as a caller-construction API.
