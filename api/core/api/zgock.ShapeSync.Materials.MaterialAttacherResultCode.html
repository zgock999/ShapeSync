public enum MaterialAttacherResultCode

Fields

Applied = 0

The requested semantics were applied or restored.

EntryBusy = 3

The entry was already applying to its Material Proxy and the request was rejected.

PartialApplied = 1

The operation succeeded, but one or more requested semantics were unsupported and ignored.

Rejected = 2

The request was rejected and its received delivery candidates were released.

RestoreFailed = 4

The Proxy entry could not be restored, so its current deliveries remain owned by the Attacher.

Remarks

PartialApplied reports a successful commit in which an unsupported semantic was ignored.
