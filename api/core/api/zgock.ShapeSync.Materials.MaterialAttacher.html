Remarks

This component does not clone, read back, copy, or retain delivery textures. A successful commit transfers delivery ownership into the Proxy.

Properties

Proxy

Gets or sets the co-located Material Proxy served by this Attacher.

public MaterialProxy Proxy { get; set; }

Property Value

MaterialProxy

A Proxy on the same UnityEngine.GameObject, or null.

Remarks

Changing this value releases every retained delivery and does not restore the previous Proxy.
