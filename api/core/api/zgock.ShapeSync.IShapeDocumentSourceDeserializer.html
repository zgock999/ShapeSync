Optional capability for decoding a standard in-memory ShapeDocument source.

public interface IShapeDocumentSourceDeserializer

Remarks

ShapeDirector uses this capability only through its configured IShapeDeserializer. The Director does not decode ShapeDocument records itself, so custom serialization formats retain ownership of their input representation.
